If I wanted to send an encoded message to my friend that only we knew how to decrypt, I'd take an original message, transform it into an encoded message, send that, and my friend would decode the encrypted message from the other side. But why would I want to send an encoded message in the first place? Could I have enemies watching over me, trying to tamper with what I send? What if they succeed, at least partially? Let's think about some possible things that could go wrong if this happens.

If we treat a code like a string of characters, then a tampering of a code would result in some original characters being deleted, some new characters being inserted, and some original characters being substituted with new ones. This sounded to me a bit like the things that go wrong during the DNA replication process though, and I've been exploring a connection between the two!
